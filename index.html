Subnetting Formula
Hosts per subnet = 2^(32 - prefix) - 2
Number of subnets = 2^(borrowed bits)
Network address = first IP in block (all host bits = 0)
Broadcast address = last IP in block (all host bits = 1)
Block size = 256 - subnet mask octet
